AI / CONTEXT ENGINEERING

Prompt ကောင်းရုံနဲ့ မလုံလောက်တော့တဲ့အခါ — Context Engineering

Kaung Htet · 26 September 2026

AI ကို Prompt ကောင်းကောင်းရေးပေးနေတာတောင် Output က တစ်ခါကောင်း၊ တစ်ခါမကောင်း ဖြစ်နေသေးတယ်ဆိုရင်— ပြဿနာက Prompt မှာပဲ ရှိချင်မှရှိတော့မယ်။

AI က ကိုယ့်အကြောင်း ဘာတွေသိထားလဲ ဆိုတာကိုပါ ပြန်ကြည့်ရမယ့်အချိန် ရောက်လာပြီ။ အဲ့ဒီနေရာမှာ Context Engineering ဝင်လာတယ်။

အရင်က AI သုံးတဲ့အခါ— “ဒီ Product အတွက် Facebook Post ရေးပေး” ဆိုပြီး Prompt တစ်ကြောင်းကို ဘယ်လိုပိုကောင်းအောင်ရေးမလဲ စဉ်းစားကြတယ်။ ဒါက Prompt Engineering။

ဒါပေမယ့် လုပ်ငန်းထဲမှာ AI ကို တကယ် System တစ်ခုလို သုံးမယ်ဆိုရင် Prompt တစ်ကြောင်းနဲ့ မလုံလောက်တော့ဘူး။

ဥပမာ Skincare Brand တစ်ခုဆိုပါစို့။ AI ကို Content ရေးခိုင်းတဲ့အချိန်—

  • Brand က ဘယ်သူလဲ။
  • ဘယ် Customer ကိုပြောနေတာလဲ။
  • Customer တွေ ဘာမေးလေ့ရှိလဲ။
  • Brand Voice ဘယ်လိုလဲ။
  • ဘယ် Product ရဲ့ အားသာချက်ကဘာလဲ။
  • အရင် Content တွေထဲမှာ ဘာတွေပြောပြီးပြီလဲ။
  • ဒီ Campaign ရဲ့ Goal ကဘာလဲ။
  • Customer Review တွေက ဘာပြောထားလဲ။
  • Sales Data ထဲမှာ ဘယ် Product က ပိုစိတ်ဝင်စားခံနေရလဲ။
  • AI က ဘယ် Files တွေကိုကြည့်လို့ရလဲ။
  • ဘယ် Tools တွေကို သုံးလို့ရလဲ။
  • အရင်က Decision တွေကို ဘာတွေမှတ်ထားလဲ။

ဒီအရာတွေ အားလုံးက Context ဖြစ်လာတယ်။

ဒါဆို မေးခွန်းက— “Prompt ကို ဘယ်လိုပိုကောင်းအောင်ရေးမလဲ?” တစ်ခုတည်း မဟုတ်တော့ဘူး။

“AI က Decision တစ်ခုချတဲ့အချိန် မှန်ကန်တဲ့ Information တွေကို မှန်ကန်တဲ့အချိန်မှာ ဘယ်လိုရနေအောင်လုပ်မလဲ?”

ဆိုတာဖြစ်လာတယ်။

Anthropic ကတောင် Context Engineering ကို Prompt Engineering ရဲ့ natural progression လို့ခေါ်ထားတယ်။

သူတို့ရဲ့ရှင်းပြချက်အရ AI Agent တစ်ခုအတွက် Context ဆိုတာ Prompt တစ်ခုတည်း မဟုတ်တော့ဘူး။ System Instructions, Tools, External Data, Message History, Memory စတဲ့ AI မြင်နိုင်တဲ့ Information Environment တစ်ခုလုံး ပါလာတယ်။

Google Cloud ကလည်း အလားတူခွဲထားတယ်။ Prompt Engineering က AI ကို ဘာလုပ်ရမလဲပြောတာ နဲ့ပိုနီးတယ်။

Context Engineering ကတော့ AI က အဲ့ဒီအလုပ်ကိုကောင်းကောင်းလုပ်နိုင်ဖို့ ဘာတွေသိထားရမလဲ၊ ဘာတွေယူသုံးလို့ရမလဲ၊ ဘယ် Information ကို ဘယ်အချိန်မှာရမလဲ ကို Design လုပ်တာနဲ့ပိုနီးတယ်။

ဒါက AI Marketing System မှာလည်း အရေးကြီးလာမယ့်အချက်ပဲ။

ဥပမာ— Prompt တစ်ကြောင်းနဲ့ Content တစ်ပုဒ်ကောင်းကောင်း ရေးထုတ်နိုင်တယ်။

ဒါပေမယ့်

  • Brand Voice သိတယ်။
  • Customer Data သိတယ်။
  • Product Information သိတယ်။
  • အရင် Campaign Result သိတယ်။
  • Customer Feedback သိတယ်။

လိုအပ်တဲ့ Tools နဲ့ Data ကို အချိန်မှန်ခေါ်သုံးနိုင်တယ်ဆိုရင်— AI က Content တစ်ပုဒ်ရေးပေးတဲ့နေရာကနေ Marketing System ထဲမှာ အလုပ်လုပ်နိုင်တဲ့ Assistant တစ်ယောက်လို ဖြစ်လာနိုင်တယ်။

ဒါကြောင့် ကျွန်တော်မြင်တာတော့ AI သုံးတတ်ဖို့အတွက် Prompt ရေးတတ်တာက အရေးကြီးနေဦးမယ်။

ဒါပေမယ့် နောက်တစ်ဆင့်မှာတော့— AI ကို ဘာမေးရမလဲဆိုတာထက် AI က ဘာတွေသိထားပြီး ဘာတွေသုံးခွင့်ရှိရမလဲဆိုတာကို Design လုပ်တတ်ဖို့ ပိုအရေးကြီးလာမယ်။

Prompt က AI ကို Instruction ပေးတယ်။

Context ကတော့ AI အလုပ်လုပ်မယ့် ကမ္ဘာကို တည်ဆောက်ပေးတယ်။
